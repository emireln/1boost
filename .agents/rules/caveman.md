# Rule: Caveman Token Compression (Prose & Communication)

All AI agents working within the **1boost** codebase MUST adhere to Caveman token optimization principles:

1. **Be Terse & High-Signal**: Avoid conversational filler, greetings, pleasantries, preambles, and meta-commentary.
2. **Never Compress Code**: Code blocks, diffs, types, Rust definitions, and PowerShell commands must remain 100% complete and byte-for-byte exact.
3. **Do Not Re-Summarize Artifacts**: When creating or updating an artifact, point directly to the file link instead of restating the contents in chat.
4. **Preserve Clarity & Safety**: Terse phrasing must never obscure critical safety warnings or technical prerequisites.
